## ✨ Features

- **🎨 Modern Dark Glassmorphic Design**: Deep cosmic canvas with atmospheric indigo and cyan ambient lighting.
- **✨ Custom Multi-Stop Gradients**: Unique, glowing tile aesthetics tailored for every denomination from `2` to `8192`+, with a pulsing aura on the `2048` tile.
- **🔤 Clean Typography**: Powered by Google Fonts (*Outfit* and *Plus Jakarta Sans*).
- **💫 Micro-Animations**: Pop-in tile spawning, merge scaling, and score-bump pulse animations.
- **🏆 High Score Persistence**: Automatically saves and loads your best score via `localStorage`.
- **🕹️ Dual Control Support**: Play using **Arrow Keys** or **W, A, S, D**.
- **📱 Mobile Touch Friendly**: Full touch swipe gesture recognition on phones and tablets.
- **🎉 Smart Game Over & Win Overlays**: Celebration modals with a "Keep Going" mode to push beyond 2048.
- **⚡ Lightweight & Fast**: Zero external libraries or frameworks—100% pure Vanilla web stack.

## 🚀 How to Run Locally

You can run this project locally on your computer using any of the following methods:

### Option 1: Using Python (Recommended)
Open your terminal in the project directory and run:
```bash
python -m http.server 5500
```
Then visit: **[http://localhost:5500/](http://localhost:5500/)**

---

### Option 2: Using Node.js / npx
```bash
npx serve -l 5500
```
Then visit: **[http://localhost:5500/](http://localhost:5500/)**

---

### Option 3: Open Directly in Browser (No Server Needed)
In PowerShell:
```powershell
Start-Process "index.html"
```
Or simply double-click the `index.html` file in File Explorer to play instantly.

## 🎮 How to Play

1. Use your **Arrow Keys** (`↑`, `↓`, `←`, `→`) or **W, A, S, D** (or swipe on touchscreens) to slide tiles across the board.
2. When two tiles with the same number collide, they merge into one with double the value!
3. Plan your moves carefully to keep the board clear and combine your way up to the **2048** tile to win.
4. Keep going after reaching 2048 to set an unbeatable high score!

## 🛠️ Tech Stack

- **HTML5**: Semantic layout with modal overlays and accessible elements.
- **CSS3**: CSS Grid, custom properties (variables), backdrop blur, gradients, and keyframe animations.
- **JavaScript (ES6+)**: Game state management, score tracking with `localStorage`, and event listeners for keyboard & touch swipes.
